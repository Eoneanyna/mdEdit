# 默认智能助手：第一阶段

新用户默认选择“智能助手（按需调用工具）”；已有明确保存的回答模式保持原选择。仍可切回笔记问答、联网搜索＋文档或通用问答。

执行路径：用户问题与最近六轮会话 → 模型选择工具 → 执行并返回资料 → 模型补查或反问 → 流式生成最终回答。工具调用使用 OpenAI 兼容的 function calling，所选模型必须支持该协议；供应商拒绝请求时会展示错误，不会伪装成已执行检索。

智能助手采用独立的回答策略：学习路线、概念解释、方案建议可直接使用模型通用知识，笔记用于补充用户背景，不强制本地检索或引用。公司内部事实仍须有本轮本地证据；用户明确要求仅依据资料时遵守范围。涉及最新版本、API和官方规格时优先检索官网。模型直接输出的完整回答会原样保留并显示，不再丢弃后重新生成；此路径当前以整段显示，调用 finish 后的最终生成仍为流式。严格的“笔记问答”模式继续限制为资料内回答。

已实现工具：

- `search_local`：本地 RAG，未命中时回退关键词搜索，支持更换检索词继续查询。
- `read_local`：按引用编号继续阅读已经找到的 Markdown/TXT，限制在当前工作区及每次100行、6000字符；不接受任意路径。
- `search_web`：使用现有实时网页搜索与正文提取。
- `read_web`：按引用编号继续阅读已找到的公共网页，每次5000字符，沿用公共网络访问限制。
- `ask_user`：缺少关键参数时结束本轮并提问，下一轮结合会话继续。
- `finish`：停止检索，整理来源并流式回答。

本地引用与网页引用在一轮中保持稳定编号。界面可展开本轮工具执行记录；执行记录目前不会随历史会话持久化。每轮最多6次模型决策、10次工具调用、18条资料，整体120秒；达到调用上限时说明限制并使用已取得资料。每次模型决策最多30秒。仅本机模式禁用网页工具，并继续限制模型端点为本机。

零件查询应先从本地确定内部编号、厂商型号和产品关联；缺少映射时反问，不能将内部编号直接当成全球零件型号。搜索结果不足以证明“所有产品均已覆盖”。文档与网页均作为不可信数据，不能授权文件写入等新操作。

尚未实现：写入学习笔记、图片生成、独立智能体协作、动态技能加载、外部搜索 MCP 接入、Word/PDF/Excel 入库。现有偏好 Markdown 文件及多轮会话功能继续可用，但不等同于任意笔记写入工具。

验证使用本地假模型与合成资料，不调用付费模型；真实模型的工具选择质量、官方来源识别和多跳召回仍需基于实际业务资料评估。工具循环会增加模型请求次数与费用，网络搜索词可能传给搜索引擎。
