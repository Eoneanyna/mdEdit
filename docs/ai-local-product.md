# 本机 AI 使用与验证

## 首次使用

1. 安装并打开 mdEdit，用 `Ctrl+Shift+A` 打开 AI 面板。
2. 配置模型。云端服务需要自己的 API Key；本机 Ollama 需要提前安装并运行聊天模型。
3. 打开学习笔记文件夹，选择「笔记问答」提问。内置检索自动启动，不需要 Python、torch 或下载嵌入模型。
4. 笔记没有相关定义时，选择「笔记 + 网页补充」，或明确使用「通用问答」。网页搜索会向搜索引擎发送检索问题。
5. 在「个人偏好与隐私」中检查默认设置，按需启用仅本机模式、关闭会话保存或关闭自动学习。

## 首次配置与连接排查（rc.2）

配置区提供「选择服务 → 测试并保存 → 打开笔记提问」提示。填好供应商、模型、Key 和接口地址后，可直接测试尚未保存的配置。成功时显示模型名称和本次请求的响应耗时，仍需点击「保存配置」才能在下次启动时沿用。

测试只发送固定的“请只回复 OK”请求，限制短输出和 15 秒等待，不附带笔记、历史或偏好，也不会触发偏好学习。云端服务仍可能收取少量模型调用费用。测试过程中可停止，不能同时问答；取消或失败后可以立即重试，问题输入框不会被清空。

401/403/404/429 等返回友好错误，不显示供应商原始响应或凭据。Ollama 失败时检查服务是否运行、模型是否已下载；首次加载较慢时可稍后重试。测试与问答共用主进程的仅本机模式限制，配置修改后会提示重新测试。

本地检索服务健康检查失败时仍保留“由应用管理”的状态，避免网络异常后重启按钮消失。

## 个人偏好文件

路径在界面中显示：应用用户数据目录下 `ai/preferences.md`。Windows 默认在 `%APPDATA%/mdedit/ai/`（以界面实际显示为准）。文件不跟随笔记工作区切换。

可直接编辑「手动偏好」，例如：

```markdown
## 手动偏好

- 默认使用中文，术语附英文。
- 解释代码时先给可运行的 Python 示例，再说明关键步骤。
- 比较方案时给出适用条件。
```

自动学习部分由两个 `mdedit:learned` 注释标记包围，只从明确的长期表达请求中归纳固定字段。不会无条件概括整段聊天，也不会从文档提取用户信息。相同偏好不会重复写入；相同字段的新偏好替换旧值。只在成功完成问答后更新，取消或失败时不更新。

界面可编辑、保存、重新加载、撤销最近一次自动学习或恢复默认模板。外部修改触发版本冲突后需重新加载。偏好只约束表达风格，不能改变资料事实、引用规则或无答案边界。

## 数据与网络边界

| 数据 | 保存位置或发送目标 | 控制 |
| --- | --- | --- |
| API Key | 本机配置，系统安全存储加密 | 模型配置中更换或清空 |
| 会话与引用片段 | Electron 本机 localStorage，按工作区隔离，明文 | 关闭保存、删除单会话、清除全部、导出 |
| 个人偏好 | 本机 Markdown，明文；启用时发送给所选模型 | 编辑、禁用、清空、撤销 |
| 云端问答 | 所选供应商：问题、最近最多 6 轮问答、当前资料、启用的偏好 | 仅本机模型模式 |
| 网页补充 | 搜索引擎收到检索问题；公共网站收到正文访问 | 回答模式或仅本机模式 |
| 检索索引 | 本机检索进程内存 | 退出或重启服务释放 |

关闭历史保存不会自动删除已有记录，当前窗口仍可继续多轮对话；重启不加载旧记录。清除全部只删除 AI 会话及引用片段；偏好、Key 和原始笔记分别管理。显式导出的 Markdown 不会随清除会话被删除。

仅本机模式限制模型为回环地址，并禁止网页补充。模型调用禁止 HTTP 重定向。网页读取逐跳验证域名/IP，阻止私网、回环、非 HTTP 地址和非标准端口，并把连接固定到已验证 IP；页面不执行脚本，限时、限体积，正文失败只保留明确标记的搜索摘要。

## 构建与验证

```sh
npm ci
npm run build:rag
node scripts/test-rag-bundle.cjs
npm run typecheck
npm run test:unit
npm run test:e2e
npm run build:win -- --publish never
```

构建检索需要 Python 3.10+ 和网络安装构建依赖。最终产物不需要系统 Python。各操作系统/架构必须原生构建，macOS 默认使用构建机架构，不能把一个架构的检索二进制同时放进两个架构的安装包。

验证覆盖偏好持久化/撤销/版本冲突、关闭自动学习、临时偏好不学习、旧会话迁移、多会话切换改名、关闭保存后重启、仅本机模式主进程拦截、内置服务自动启动/索引/重启，以及空 PATH 下冻结检索程序的令牌和检索。网页解析测试覆盖搜索引擎切换、正文提取、摘要回退、取消和公共地址限制。

2026-11-03 在 Windows x64 上完成类型检查、单元测试、23 个 Electron 端到端用例、7 个 Python 用例及空 PATH 的打包应用验证。公共问题「RAG的定义是什么」实测得到相关网页正文及明确标记的搜索摘要。新增相关性过滤，避免多词技术问题仅命中普通单词的词典页面。安装包为 `mdEdit-0.2.0-win-x64.exe`；macOS/Linux 构建配置与 CI 已接入，本机未验证其安装包。

同时更新了生产依赖的兼容补丁；`npm audit --omit=dev` 剩余 4 个低危项，均属于现有数学公式依赖链，当前不启用 LaTeX 特性。没有通过强制降级编辑器来消除此提示；开发依赖审计仍有待独立升级处理。

限制：内置检索为轻量 BM25 + 哈希向量，非深度语义检索；只支持 Markdown/纯文本，不摄取 PDF/Word；网页服务可能被限流或验证码拦截；偏好自动学习使用保守规则，复杂偏好需手动编辑；引用编号检查不能证明每条结论都被引用支持。
