# 引用定位、编辑上下文与无答案边界

本轮实现：

- 本地来源携带标题、原文片段和起止行号，回答中的有效编号可以点击定位；编辑器跨 Markdown 样式边界匹配，正文变化时报告部分匹配或未找到。
- 「当前文档」「当前选区」显式提供本轮上下文。未保存内容必须勾选确认，发送前即时比较内容，避免编辑器变更通知延迟造成漏检。
- 选区模式只发送选中文字，当前文档上限 60000 字符、选区上限 12000 字符。长文档最多选 6 块；总结按分布采样，不能视为完整全文审阅。
- 编辑快照引用附带文档摘要，点击前核对当前内容；不自动恢复旧快照，不覆盖原文件。
- 完全没有检索资料时直接返回依据不足；资料不足、冲突和文档内指令由系统提示词约束，不能保证模型始终遵守。
