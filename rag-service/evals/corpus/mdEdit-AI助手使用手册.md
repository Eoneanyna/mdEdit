# mdEdit AI 助手使用手册

## 功能入口

顶部菜单「AI」(快捷键 Ctrl+Shift+A)打开右侧 AI 助手抽屉。左侧是文件树和大纲,AI 对话在右侧独立面板,互不干扰。

## 模型配置

点击「配置」展开设置区:

- OpenRouter:有免费模型,模型名形如 `deepseek/deepseek-chat-v3-0324:free`,免费通道偶尔限流(429),可换其他带 `:free` 的模型
- SiliconCloud:模型名带组织前缀,如 `deepseek-ai/DeepSeek-V3`
- Ollama:本地模型完全免费,模型名填 `qwen2.5:7b`,API Key 留空

配置保存后持久化在本地,「配置」区可收起,空间留给对话。

## 本地检索(RAG)

勾选「搜索本地 .md」后,提问会自动调用本地 RAG 服务(端口 8765)做混合检索。启动方式:

```
cd rag-service
python -m uvicorn app.main:app --port 8765
```

RAG 服务不可用时自动回退到内置关键词搜索。回答中的引用编号 [1] [2] 对应下方来源列表,点击来源可打开对应文件。

## 常见问题

- 404 模型不可用:检查模型名是否需要组织前缀,免费模型是否已下线
- 429 限流:免费通道拥挤,稍后重试或换模型
