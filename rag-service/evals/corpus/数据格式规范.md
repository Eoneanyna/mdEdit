# 数据格式规范

## 标注产出文件格式

标注结果统一为 JSONL,每行一个 JSON 对象,UTF-8 编码。字段定义:

- `task_id`:字符串,任务唯一标识,格式 `T-YYYYMMDD-序号`,如 `T-20261028-0001`
- `text`:原始文本,不做任何清洗
- `label`:枚举值,情感任务为 positive/negative/neutral/mixed
- `annotator`:标注员工号
- `quality_checker`:质检员工号,未质检为 null
- `timestamp`:ISO8601 带时区,如 `2026-10-28T14:30:00+08:00`
- `version`:规范版本号,当前为 `v3`

## 交付目录结构

```
delivery/
  T-20261028/
    part-001.jsonl   单文件不超过 50MB
    manifest.json    记录文件清单与 sha256
```

## 校验规则

交付前必须通过 `validate.py`:必填字段缺失率必须为 0,label 枚举越界条数必须为 0,task_id 重复数必须为 0。校验失败的批次直接打回,不进入验收。
